# ResearchArena

ResearchArena is a GenLayer-native competitive research bounty marketplace.

A sponsor locks native GEN with a research question and scoring rubric. Independent researchers submit public reports and evidence URLs. The Intelligent Contract fetches the live evidence, evaluates competing submissions with an LLM, reaches validator consensus on the best-supported answer, and allows the winning researcher to claim the escrowed reward.

This repository contains the Intelligent Contract, direct tests, live Studionet integration tests, CI, and a Next.js frontend.
